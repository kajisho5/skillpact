# Roadmap

Dates are not promised; items move when review finds problems.

## Now: draft 0.8
- Fixes from the v0.7 self-review (full file coverage, signed roles, sandboxed tests, normative globs, I-JSON).
- English normative text, Japanese translation, explanatory pages (why, rationale, guides).

## Next: public review
- Announce, collect feedback for 30 days (REVIEW.md), publish decisions on each comment.
- Independent re-check of the harness mappings against current harness documentation.

## Then: 1.0
- Stable schema URLs and stability rules (spec §17).
- Packages on PyPI and npm; signed release tags; production Sigstore signing of samples.
- Consider IANA media type registration (after 1.0).

## Later (proposals welcome)
- Revocation list format for compromised keys.
- Seatbelt (macOS) sandbox mode: promote from experimental after field use.
- More harness targets and runtime policy exports.
