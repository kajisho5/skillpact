# About this specification

Status, governance, legal and practical information. See also the [specification](../spec/), [design rationale](../rationale/) and [why SkillPact](../why/).

## Status
Draft 0.8 (2026-10-22), editor's draft, not stable. The English specification is normative; the Japanese one is a translation. No version 1.0 exists yet; the public review dates are not set.

## Governance and decision process
The editor is shogo kajiyama (SEVENTHWELL). Changes follow the SkillPact Proposal process in [GOVERNANCE.md](https://github.com/kajisho5/skillpact/blob/main/GOVERNANCE.md): an issue, at least 7 days of discussion, a pull request that updates spec, schema, conformance suite and both implementations together, and a written decision. How to contribute: [CONTRIBUTING.md](https://github.com/kajisho5/skillpact/blob/main/CONTRIBUTING.md). Conduct: [CODE_OF_CONDUCT.md](https://github.com/kajisho5/skillpact/blob/main/CODE_OF_CONDUCT.md).

## Security reports
Report vulnerabilities privately to kajiyama@seventh-well.com or through GitHub private vulnerability reporting. See [SECURITY.md](https://github.com/kajisho5/skillpact/blob/main/SECURITY.md).

## Media type and file naming
The file is always `skill.contract.json`. It is served as `application/json`; no specific media type is registered; IANA registration is to be considered after 1.0 (spec Appendix D).

## Accessibility of this site
Pages use semantic HTML with a language attribute, one main heading, table headers, visible focus and sufficient colour contrast; the checker works with the keyboard. Report problems as GitHub issues. See [ACCESSIBILITY.md](https://github.com/kajisho5/skillpact/blob/main/ACCESSIBILITY.md).
