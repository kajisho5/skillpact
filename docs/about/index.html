About this specification

Status, governance, legal and practical information. See also the specification, design rationale and why SkillPact.

Status

Draft 0.8 (2026-10-22), editor's draft, not stable. The English specification is normative; the Japanese one is a translation. No version 1.0 exists yet; the public review dates are not set.

Governance and decision process

The editor is shogo kajiyama (SEVENTHWELL). Changes follow the SkillPact Proposal process in GOVERNANCE.md: an issue, at least 7 days of discussion, a pull request that updates spec, schema, conformance suite and both implementations together, and a written decision. How to contribute: CONTRIBUTING.md. Conduct: CODE_OF_CONDUCT.md.

Security reports

Report vulnerabilities privately to kajiyama@seventh-well.com or through GitHub private vulnerability reporting. See SECURITY.md.

Intellectual property

  • Specification text: CC BY 4.0. Schemas, conformance suite and implementations: Apache-2.0, which includes a patent license from each contributor for their contributions.
  • SEVENTHWELL is not aware of patents essential to implementing this specification. Whether to add a formal patent non-assertion covenant for the specification text will be decided before 1.0. See IPR.md.

Trademarks and badges

"SEVENTHWELL" is the name of the publisher. "SkillPact" may be used to describe implementations and contracts that follow the specification. Show an L1/L2/L3 badge only for the level your CI or skillpact conformance actually reports, and do not suggest endorsement by SEVENTHWELL. See TRADEMARKS.md.

Citation

Use CITATION.cff: "SkillPact Specification, draft 0.8, SEVENTHWELL, 2026."

Roadmap

See ROADMAP.md. Next: public review, then 1.0 with stable schema URLs and published packages.

Media type and file naming

The file is always skill.contract.json. It is served as application/json; no specific media type is registered (spec Appendix D).

Accessibility of this site

Pages use semantic HTML with a language attribute, one main heading, table headers, visible focus and sufficient colour contrast; the checker works with the keyboard. Report problems as GitHub issues. See ACCESSIBILITY.md.
