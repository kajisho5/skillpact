Checker · runs in your browser

Check a skill.contract.json

Paste a contract. Schema validation, cross-checks, risky effects and ed25519 signatures are checked locally in this page (the TypeScript implementation compiled for the browser). Nothing is uploaded: the page's security policy only allows loading files from this site (e.g. the example), never sending your input.

Not checked here: files listed in integrity.files (the page only sees the contract), conformance tests (L2), Sigstore bundles. Use pipx run skillpact conformance <dir> or the GitHub Action for the full level.
