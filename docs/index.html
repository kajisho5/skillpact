Machine-readable contracts
for Agent Skills

A skill.contract.json next to an unchanged SKILL.md. The author declares every effect, ships tests that run network-isolated, and signs it. Harnesses check it before install.

Schema reference → GitHub

Six effects

readReads files or data
writeCreates or modifies files
networkTalks to hosts
execRuns other programs
spendSpends money
sendSends messages

Three levels

L1declared

Valid contract.

L2tested

Conformance tests pass offline.

L3signed

Hashes + trusted ed25519 or Sigstore signature.

One policy, every harness

A harness policy decides allowaskdeny per effect and compiles to Claude Code, Cursor, Codex and Gemini CLI configs. Runtime enforcement is left to APS, ACS and HushSpec (export provided).

skillpact conformance ./my-skill
skillpact policy-compile ./my-skill policy.json --target claude-code
skillpact convert ./my-skill --to mda
