SkillPact

Machine-readable contracts for Agent Skills — by SEVENTHWELL

A skill.contract.json next to an unchanged SKILL.md. The author declares every effect (read · write · network · exec · spend · send), ships tests that run network-isolated, and signs it (ed25519 or Sigstore). Harnesses check it before install.

LevelMeaning
L1 declaredvalid contract
L2 testedconformance tests pass offline
L3 signedhashes + trusted signature

One policy, every harness

A harness policy decides allow / ask / deny per capability and compiles to Claude Code, Cursor, Codex and Gemini CLI configs. Runtime enforcement is left to APS, ACS and HushSpec (export provided).

skillpact conformance ./my-skill
skillpact policy-compile ./my-skill policy.json --target claude-code
skillpact convert ./my-skill --to mda
