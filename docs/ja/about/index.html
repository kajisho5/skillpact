この仕様について

位置づけ、運営、法的な事項、実務的な情報です。仕様、設計の理由、なぜ SkillPact かもご覧ください。

位置づけ

ドラフト 0.8（2026-10-22）。編集者によるドラフトで、安定版ではありません。英語の仕様が規範で、日本語は翻訳です。1.0 はまだありません。公開レビューの日程は未定です。

運営と決め方

編集者は shogo kajiyama（SEVENTHWELL）です。変更は GOVERNANCE.md の手順に従います：issue を立て、7 日以上議論し、仕様・スキーマ・適合スイート・両実装をまとめて更新するプルリクエストを出し、理由を書いて決定します。参加の仕方は CONTRIBUTING.md、行動規範は CODE_OF_CONDUCT.md。

脆弱性の報告

kajiyama@seventh-well.com か、GitHub の非公開の脆弱性報告で知らせてください。SECURITY.md。

商標とバッジ

「SEVENTHWELL」は発行者の名前です。「SkillPact」は、仕様に従う実装や契約を説明するために使えます。L1/L2/L3 のバッジは、CI か skillpact conformance が実際に出したレベルだけを表示し、SEVENTHWELL の推薦を受けたように見せないでください。TRADEMARKS.md。

メディアタイプとファイル名

ファイル名は常に skill.contract.json です。application/json で配信し、専用のメディアタイプは登録しておらず、IANA 登録は 1.0 の後に検討します（仕様の付録 D）。

このサイトのアクセシビリティ

言語属性つきの意味のある HTML、ページごとに 1 つの見出し、表の見出し、見えるフォーカス、十分な色のコントラストを使っています。チェッカーはキーボードで操作できます。問題は GitHub issue で知らせてください。ACCESSIBILITY.md。
