Agent Skills のための
機械が読める契約

変更しない SKILL.md の隣に skill.contract.json を置きます。作者はすべての副作用を宣言し、ネットを切って動くテストを付け、署名します。ハーネスはそれをインストール前に確かめます。

スキーマの説明 → ブラウザで確認

なぜ必要か

エージェントのスキルはあなたの権限で動きますが、SKILL.md は文章で、入れる前に機械で確かめられるものがありません。SkillPact はツールが先に確かめられる契約を加えます。スキルが何に触れうるかが分かり、ポリシーが allow / ask / deny を決め、ファイルの変更も検出できます。スキルが安全だと証明するものではありません。なぜ SkillPact か →

6 種類の副作用

readファイルやデータを読む
writeファイルを作る・変える
network外部と通信する（@local は手元・社内網だけ）
exec他のプログラムを動かす
spendお金を使う
send人にメッセージを送る

3 つのレベル

L1宣言済み

契約が正しい形をしている。

L2テスト済み

適合テストがネットを切った状態で通る。

L3署名済み

ハッシュと、信頼できる作者の署名（ed25519 か Sigstore）。

1 つのルールを、すべてのハーネスに

ハーネスのポリシーが副作用ごとに 許可確認拒否 を決め、Claude Code・Cursor・Codex・Gemini CLI の設定に変換します。実行中の強制は APS・ACS・HushSpec に任せます（書き出しに対応）。

skillpact conformance ./my-skill
skillpact policy-compile ./my-skill policy.json --target claude-code
skillpact convert ./my-skill --to mda
