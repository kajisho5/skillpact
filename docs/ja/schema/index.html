skill.contract.json とハーネスポリシー

契約ファイルは SKILL.md と同じフォルダに置く JSON です。全項目の型・必須・取りうる値は英語版の項目別リファレンスにあります。ここでは全体の形だけを説明します。

v0.7.json 契約policy-v0.7.json ポリシー

契約の主な項目

項目内容
contract_version仕様の版（最新は "0.7"）。知らない版は拒否されます。
skillスキルの名前と版。名前は SKILL.md の name、およびフォルダ名と同じにします。
permissions6 種類の副作用それぞれの上限（none / scoped / any）と範囲。
capabilitiesツール・コマンドごとの副作用、入口、入出力のスキーマ。
requirements必要なプログラム、ランタイム、パッケージ、他のスキル、環境変数（値は書かない）。
testsネットを切って動く適合テスト。全部通れば L2。
integrityファイルのハッシュと署名。信頼できる作者（author）の署名があれば L3。レビュアーの署名は証明として別に報告されます。
x拡張用（x.<ベンダー名>）。検証者は中身を無視して進めます。

署名の対象

v0.4 以降は、integrity.signatures を除いた契約全体を RFC 8785（JCS）で正規化したバイト列に署名します。
