The six effects

Every contract declares a level for each effect (none · scoped · any); every capability lists the effects it may cause.

readReads files or dataffmpeg-skill: scoped
writeCreates or modifies filesffmpeg-skill: scoped
networkTalks to hosts over the networkffmpeg-skill: scoped
execRuns other programsffmpeg-skill: scoped
spendSpends money / paid quotaffmpeg-skill: none
sendSends messages to people or servicesffmpeg-skill: none

Conformance levels

L1declared

Valid against the contract schema.

L2tested

tests.cases pass with the network cut off.

L3signed

integrity hashes match and a trusted ed25519 / Sigstore signature verifies.

Policy decisions

allow

Run without asking.

ask

Ask the user first.

deny

Block install or call.
